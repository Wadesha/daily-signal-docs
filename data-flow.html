// 伪代码：并行采集引擎
async function collectSources():
  results = []
  for each source in SOURCE_REGISTRY:
    // 所有信源并行采集，单个失败不影响整体
    result = try_async(source.fetch())
    log_source_health(source.id, result.status)
    if result.success:
      results.append(result.normalize())
  return results

关键设计：单个信源故障不会导致整个 pipeline 中断，每信源的健康状态被记录用于长期监控。

阶段二：Processing — 处理

标准化（Normalization）

每条原始数据被转换为统一的内部数据模型：

{
  "source_id": "A",              // 信源标识
  "source_type": "AIS data",     // 信源类型
  "source_reliability": "A2",    // 预置可靠性评级
  "timestamp": "ISO 8601",       // 标准化时间戳
  "entity": "MSC Aries",         // 主要实体
  "event_type": "route_deviation", // 事件类型
  "raw_text": "...",             // 原始文本
  "location": {"lat": 26.5, "lon": 56.0}, // 地理位置
  "dedup_hash": "sha256[:16]",   // 去重哈希
  "simhash": "63-bit"            // 语义相似度哈希
}

去重（Deduplication）

三层去重机制，确保同一条信息不被重复计入：

层级 方法 说明
精确去重 URL sha256[:16] 同一篇文章来自不同聚合器时命中
语义去重 63-bit simhash, Hamming ≤ 3 同一事件的不同表述时命中
时间窗口 14 天滑动窗口 SQLite 超过 14 天的旧信息不再去重（可能重新浮现） 
// 伪代码：去重管道
def deduplicate(signals, seen_db, window_days=14):
  result = []
  for s in signals:
    if s.url_hash in seen_db.last_14days:
      continue  // 精确去重命中
    if any(hamming(s.simhash, seen) <= 3 for seen in seen_db.simhash_window):
      continue  // 语义去重命中
    result.append(s)
    seen_db.record(s.url_hash, s.simhash)
  return result

阶段三：Analysis — 分析

3.1 — STEMPLES Plus 维度映射

每条信号被映射到 11 个评估维度中的一个或多个，识别跨维度交互：

// 伪代码：维度映射
def map_dimensions(signal):
  dimensions = []
  if involves_military_activity(signal): dimensions.append("Military")
  if affects_trade_or_markets(signal):   dimensions.append("Economic")
  if has_official_statement(signal):     dimensions.append("Political")
  if has_technical_data(signal):         dimensions.append("Technical")
  if affects_safety(signal):             dimensions.append("Security")
  if involves_cultural_or_religious(signal): dimensions.append("Religion")
  if changes_demographic_conditions(signal): dimensions.append("Demographics")
  if has_psychological_impact(signal):   dimensions.append("Psychology")
  // ... 其余维度
  return dimensions

3.2 — 交叉验证矩阵

对核心假设进行多信源交叉验证，计算独立验证次数：

// 伪代码：交叉验证
def cross_validate(hypothesis, signals):
  supporting = 0
  opposing = 0
  independent_sources = set()

  for signal in signals:
    if signal.supports(hypothesis):
      supporting += 1
      independent_sources.add(signal.source_id)
    elif signal.opposes(hypothesis):
      opposing += 1

  return {
    "supporting_signals": supporting,
    "opposing_signals": opposing,
    "independent_sources": len(independent_sources),
    "verdict": "CONFIRMED" if (supporting >= 3 and opposing == 0) else "PARTIAL" if (supporting > opposing) else "REJECTED"
  }

3.3 — 竞争性假设分析（ACH）

列出所有可能的解释，对每个证据评估它对每个假设的"一致性程度"：

证据 / 假设 H1: 未公开演习 H2: 天气改道 H3: 美军行动 H4: 数据误报
AIS 商船改道 CC C N II
保险费率翻倍 CC I C II
运营商内部通报 CC C N II
航母行程推迟 C I CC II
伊朗官方宣布演习 CC N I II
卫星影像 7 艘军舰 CC II C II

评级标准：CC=强烈支持 · C=支持 · N=中立 · I=不一致 · II=强烈不一致

ACH 诊断结论： H1（未公开演习）在所有假设中"最不被证伪"——没有任何证据强烈反对它，且有最多的 CC 评级。H2 和 H4 因被 II 评级多次命中而排除。

阶段四：Ranking — 排名

综合评分公式

Score = Severity_Weight × Confidence_Score × Source_Weight

其中：
  Severity_Weight:
    HIGH    = 1.0
    MODERATE = 0.6
    LOW     = 0.3

  Confidence_Score: 0.00 - 1.00
    基于信源数量、独立性、ACH 诊断结果

  Source_Weight:
    聚合信源可靠性的加权平均 (A1=1.0 → F6=0.1)

// 伪代码：模式识别
def synthesize_signals(signals):
  patterns = []
  for each pair in combinations(signals, 2):
    if share_common_dimension(pair):
      patterns.record({
        "signal_a": pair[0].id,
        "signal_b": pair[1].id,
        "shared_dimension": find_common_dimension(pair),
        "relationship": determine_relationship(pair)
        // 领先(leading)、滞后(lagging)、因果(causal)、巧合(coincidental)
      })
  return generate_assessment(patterns)
