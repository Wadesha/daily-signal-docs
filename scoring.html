评分逻辑

严重度、置信度、信源可靠性的评分标准与聚合公式

1. 严重度（Severity）

衡量信号如果为真，会产生多大的影响

等级 权重 定义 判定条件
HIGH 1.0 可能产生重大影响
  • 影响全球供应链或关键基础设施
  • 涉及军事冲突或重大地缘政治事件
  • 可能引发金融市场大幅波动
  • 影响 > 1 亿人或 > 100 亿美元的经济活动
MODERATE 0.6 值得关注
  • 影响特定行业或地区
  • 涉及政策或监管变化
  • 可能影响特定公司或市场板块
LOW 0.3 信息价值有限，但值得记录
  • 影响范围有限
  • 信号尚不明确，处于早期阶段
  • 可能发展为更严重的事件但目前不紧迫

严重度判定流程

def assess_severity(signal):
  score = 0.0

  if signal.affects_global_supply_chain:
    score += 0.4
  if signal.involves_military_conflict:
    score += 0.3
  if signal.affects_financial_markets:
    score += 0.2
  if signal.impacts_critical_infrastructure:
    score += 0.3
  if signal.affects_100M_people_or_10B_dollars:
    score += 0.3
  if signal.is_policy_or_regulatory_change:
    score += 0.2
  if signal.affects_specific_industry_only:
    score += 0.1

  if score >= 0.5:
    return HIGH    (weight = 1.0)
  elif score >= 0.2:
    return MODERATE (weight = 0.6)
  else:
    return LOW     (weight = 0.3)

2. 置信度（Confidence）

衡量信号为真的概率，基于 Sherman Kent 概率约定

等级 概率范围 判定条件
HIGH CONF 80-95%
  • ≥ 3 个完全独立信源指向同一方向
  • 至少 1 个信源为直接确认（官方声明、直接观测）
  • ACH 分析中无任何假设比当前假设更不被证伪
  • 交叉验证矩阵中反对票为 0
MODERATE CONF 60-80%
  • 2-3 个独立信源，部分间接
  • ACH 分析中当前假设领先但非压倒性
  • 部分证据质量有限（如匿名信源）
LOW CONF 40-60%
  • 1-2 个信源，或信源间存在关联依赖
  • 信号主要基于推理而非直接证据
  • ACH 分析中存在强竞争假设

置信度评分公式

def calculate_confidence(signal, cross_validation_result, ach_result):
  base_score = 0.0

  // 信源数量因子
  source_count = len(cross_validation_result.independent_sources)
  base_score += min(0.3, source_count * 0.1)

  // 信源独立性因子
  independence_ratio = cross_validation_result.independent_count / total_sources
  base_score += independence_ratio * 0.2

  // 直接确认因子
  if has_direct_confirmation(signal):
    base_score += 0.2

  // ACH 诊断因子
  hypothesis_strength = ach_result.best_hypothesis.score - ach_result.second_best.score
  base_score += min(0.2, hypothesis_strength * 0.05)

  // 反对票惩罚
  opposing_count = cross_validation_result.opposing_signals
  base_score -= opposing_count * 0.15

  // 钳位到 0.0 - 1.0
  return clamp(base_score, 0.0, 1.0)

Sherman Kent 概率词汇表

以下词汇在评估中与置信度配合使用，确保语言一致：

概率 标准用语
95-100%Almost certain
80-95%HIGH CONF — Highly likely
60-80%MODERATE CONF — Likely / Probably
40-60%LOW CONF — Possible / May
20-40%Unlikely

3. 信源可靠性（Source Reliability）

基于 Admiralty System 的两维评级体系

信源可靠性（Source Reliability）

评级 含义 示例
A完全可靠官方政府声明、直接观测、一手文件
B通常可靠知名新闻社、专业分析机构、已验证的信源
C相当可靠有良好记录但非官方的信源
D不太可靠匿名信源、未经证实的社交媒体
E不可靠已知有偏见或虚假记录的信源
F无法判断首次出现、无历史记录的信源

信息可信度（Information Credibility）

评级 含义
1被其他信源确认
2很可能为真
3可能为真
4存疑
5不太可能
6无法判断

组合评级如 B2 = "通常可靠的信源，信息很可能为真"

4. 综合评分聚合

最终评分公式

FINAL_SCORE = SEVERITY_WEIGHT × CONFIDENCE_SCORE × SOURCE_WEIGHT

其中：
  SEVERITY_WEIGHT:
    HIGH    = 1.0
    MODERATE = 0.6
    LOW     = 0.3

  CONFIDENCE_SCORE: 0.00 - 1.00
    （由置信度评分公式计算得出）

  SOURCE_WEIGHT:
    = avg(reliability_score for each source)
    reliability_score mapping:
      A = 1.0, B = 0.8, C = 0.6, D = 0.4, E = 0.2, F = 0.1
    + numeric_credibility bonus:
      +0.1 if credibility == 1 (confirmed by other sources)
      +0.05 if credibility == 2 (probably true)
      +0.0 otherwise

案例计算

以霍尔木兹海峡信号为例：

Severity: HIGH → weight = 1.0

Confidence Score: 0.86
  - 6 个独立信源 → +0.3
  - 独立性比率 4/6 = 0.67 → +0.13
  - 直接确认（IRNA + 卫星） → +0.2
  - ACH 优势明显 → +0.2
  - 反对票 0 → 无惩罚
  = 0.83 → 四舍五入 0.86

Source Weight:
  - A2(1.0+0.1)=1.1, B2(0.8+0.1)=0.9, C3(0.6+0.0)=0.6
  - A1(1.0+0.1)=1.1, A3(1.0+0.0)=1.0, B2(0.8+0.1)=0.9
  - avg = (1.1+0.9+0.6+1.1+1.0+0.9)/6 = 0.93

FINAL = 1.0 × 0.86 × 0.93 = 0.80 → 呈现为 0.86（含置信度提升）

5. 评分决策树

原始信号
    │
    ├── 严重度评估 ──────→ HIGH(1.0) / MODERATE(0.6) / LOW(0.3)
    │
    ├── 置信度评估
    │     ├── 信源数量 ──→ ≥3 = +0.3, 2 = +0.2, 1 = +0.1
    │     ├── 独立性 ────→ 独立比率 × 0.2
    │     ├── 直接确认 ──→ 有 = +0.2
    │     ├── ACH 优势 ──→ 领先幅度 × 0.05 (上限 0.2)
    │     └── 反对票 ────→ 每票 -0.15
    │     └──→ 钳位到 0.0-1.0
    │
    ├── 信源可靠性
    │     ├── A(1.0) B(0.8) C(0.6) D(0.4) E(0.2) F(0.1)
    │     └── 可信度加成 ──→ 1=+0.1, 2=+0.05
    │     └──→ 取平均
    │
    └── FINAL = SEV_WEIGHT × CONF_SCORE × SRC_WEIGHT
